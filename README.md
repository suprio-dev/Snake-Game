# 🐍 Snake Game in C

A simple **console-based Snake Game coded in C** 

## 🎮 About

- 🐍 Move the snake around the board
- 🍎 Eat the food (`[]`)
- 📈 Increase your score
- 🧱 Don't let the snake hit it's own body
- ❌ Quit whenever you want

## 🛠️ Tech Stack

- **C**
- **GCC**
- **Windows Console**

### Libraries

- `stdio.h` — Input/output
- `stdlib.h` — Utility functions and system commands
- `conio.h` — Keyboard input
- `windows.h` — Windows console support
- `time.h` — Random food positioning

## 🎮 Controls

| Key | Action |
|---|---|
| `W` | Move Up ⬆️ |
| `S` | Move Down ⬇️ |
| `A` | Move Left ⬅️ |
| `D` | Move Right ➡️ |
| `Q` | Quit ❌ |
